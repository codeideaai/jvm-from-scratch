# 新手学习路线

[English](../en/tutorial/beginner-guide.md) · [中文](新手学习路线与补齐说明.md)

## 阅读前的准备

本系列通过概念解释、逐步推演和可运行实验介绍 JVM。学习时先理解术语和前置概念，再运行代码并解释输出；遇到困难时，可按下表回到对应先修课。

这里的“新手”指刚开始学 JVM。若从未写过 Java，至少先掌握变量、if、循环、方法、类与对象，再进入复杂实验。F01 负责带你编译运行，不会假装一篇文章就能替代整门 Java 语言课。

## 不必按数字一次读完

| 阶段 | 阅读顺序 | 过关条件 |
| --- | --- | --- |
| 把程序跑起来 | F01 → F02 → F03 | 能说明源码、class、进程；能手算一次操作数栈 |
| 理解执行 | 01 → 02 → 03 → 05 → 06，再读 04 | 能区别类初始化、方法调用和对象创建 |
| 理解存活与故障 | F04 → F05 → 08 → 09 → 18 | 能画引用路径，区分泄漏、OOM 与 GC 压力 |
| 理解共享状态 | F06 → 10 → 11 → 12 | 能画出丢失更新，并写出发布链 |
| 开始诊断 | 16 → 13 → 14 → 15 | 能为一个假设选证据，不拿一次耗时当结论 |
| 第二遍拓展 | 07 的句柄/Lambda、17、19 | 先知道它们解决什么问题，再探索实现细节 |

每次读一小节，先预测、再运行、再解释。一天读多少篇不作为过关标准。卡在术语时，返回对应先修课，没必要反复背当前段落。

## 用问题判断是否真的理解

1. 两个变量指向同一对象，给其中一个变量赋 null，另一个还能访问吗？能；变量重新赋值不删除另一路引用。
2. 250 MiB 累计分配一定需要至少 250 MiB 最大堆吗？不一定；同时存活量与回收行为才决定这次负载的容量压力。
3. volatile 能让两个分开的读写自动变成原子加法吗？不能；F06 用固定交错演示了这个区别。
4. 出现 OutOfMemoryError 一定存在泄漏吗？不一定；业务所需存活集也可能超过合理但偏小的配置。
5. 看见 GC 后占用下降，能断言全部不用的对象都已经归还给操作系统吗？不能；这是不同层次的结论。
6. javap 中看到调用，机器执行时一定还存在同样的调用吗？不能据此确定，JIT 可能内联。

答不出来时看对应图或时序表，而不是只记答案。
