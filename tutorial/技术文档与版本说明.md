# 技术文档与版本说明

[English](../en/tutorial/sources.md) · [中文](技术文档与版本说明.md)

## 规范与官方参考

- [JVMS 17](https://docs.oracle.com/javase/specs/jvms/se17/html/index.html)：运行时类型、类加载与字节码语义。
- [JLS 17](https://docs.oracle.com/javase/specs/jls/se17/html/index.html)：表达式、泛型、初始化与内存模型。
- [JDK 17 java 命令](https://docs.oracle.com/en/java/javase/17/docs/specs/man/java.html)：日志与诊断参数。
- [OpenJDK JMH](https://github.com/openjdk/jmh)：基准工程和注解处理器。
- [JEP 416](https://openjdk.org/jeps/416)：JDK 18 反射实现调整。
- [JEP 410](https://openjdk.org/jeps/410)：JDK 17 移除实验性 AOT/JIT 编译器。
- [GraalVM Native Image](https://www.graalvm.org/latest/reference-manual/native-image/basics/)：本地镜像概念；latest 文档会变动，应结合实际工具版本。

规范负责语义保证，HotSpot 诊断输出负责实现观察。正文中 JDK 版本、日志观察与代码验证彼此区分；没有把一次观测写成所有 JVM 的永久规律。
